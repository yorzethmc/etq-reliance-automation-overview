# ETQ Reliance Automation Engineering

## Español

Proyecto independiente de ingeniería y documentación para automatizaciones de ETQ Reliance. El trabajo se concentra en patrones seguros para ETQScript/Jython, Task Profiles, utilidades reutilizables, consultas SQL, observabilidad y promoción controlada entre DEV, VAL y PROD.

La documentación completa y el código se mantienen en un repositorio privado. El contenido interno incluye análisis originales, decisiones de diseño, comparaciones entre implementaciones legacy y optimized, riesgos, pruebas y procedimientos de validación.

### Solicitar acceso

Abra un issue en este repositorio con:

- su usuario de GitHub;

No incluya información confidencial, datos personales ni detalles de ambientes productivos en la solicitud pública. El acceso se evalúa individualmente y no está garantizado.

## English

Independent engineering and documentation project for ETQ Reliance automations. The work focuses on safe patterns for ETQScript/Jython, Task Profiles, reusable utilities, SQL queries, observability, and controlled promotion across DEV, VAL, and PROD.

The complete documentation and source code are maintained in a private repository. Internal content includes original analysis, design decisions, legacy-versus-optimized implementation comparisons, risks, tests, and validation procedures.

### Request access

Open an issue in this repository and provide:

- your GitHub username;
- the purpose of your request;
- the module or topic you need to review.

Do not include confidential information, personal data, or production-environment details in the public request. Access is reviewed individually and is not guaranteed.
